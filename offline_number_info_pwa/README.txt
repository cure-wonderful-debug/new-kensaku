番号・情報検索 — iPhone向けオフライン版

内容
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面アプリ設定
- sw.js: 初回アクセス後にアプリ本体をキャッシュするオフライン機能
- icon-180.png / icon-192.png / icon-512.png: ホーム画面用アイコン（指定画像）

GitHub Pagesで公開する場合
1. GitHubで新しいリポジトリを作る（個人情報や登録データはリポジトリに入れない）。
2. このフォルダ内の3ファイルをリポジトリのルートにアップロードする。
3. Settings > Pages で公開設定を行い、発行されたHTTPS URLをiPhoneのSafariで開く。
4. ページを開いたまま少し待ち、アプリが読み込まれたことを確認する。
5. Safariの共有メニューから「ホーム画面に追加」を選ぶ。
6. いったんオンラインのままホーム画面アイコンを開き、画面が正常に表示されることを確認する。
7. 機内モードにしてホーム画面アイコンから再度開き、検索・登録・編集が使えるかテストする。

重要
- GitHub Pagesからアプリ本体を最初に取得する時はインターネットが必要です。キャッシュ後はアプリ画面をオフラインで開けるようにしています。
- 入力した情報はiPhone上のブラウザ/Webアプリのローカル保存領域に保存し、コード上では外部送信・解析・広告・外部ライブラリを使用しません。
- GitHub Pagesの公開ページは誰でも閲覧できる可能性があります。入力した実データはGitHubにアップロードしないでください。
- アプリの削除、Safari/Webアプリの保存データ消去、端末故障などで登録情報を失う可能性があります。重要な情報を登録する前に、機内モードでの動作と保存・再起動後の再表示をテストしてください。
- ロックはアプリ内の操作を防ぐ機能です。端末やブラウザの保存領域そのものを暗号化する機能ではありません。
- この版は保存キーを新しくしているため、以前の試作品の登録データは読み込みません。以前のデータ自体は削除していません。
